# Stellar Party

Multiplayer star game with login, rooms, friends, chat, and a leaderboard.

## Put it on GitHub

Unzip this folder. Upload these files to a new GitHub repo so `package.json` is at the top of the repo, not inside another folder.

Do not upload `node_modules`. It is not included.

## Render

New → Web Service → connect the repo.

- Build command: `npm install`
- Start command: `npm start`

Deploy. Open the site link when the log says `Stellar Party running on port`.
